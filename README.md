## 🚀 Cara Instalasi (1-Klik)

1. **Unduh** berkas [`AncamanSetup.zip`](AncamanSetup.zip?raw=true).
2. **Ekstrak** isi file `.zip` ke komputer Anda.
3. Di dalam folder hasil ekstrak, cukup **klik 2x file `Setup.bat`**.
4. Klik **Yes** saat Windows meminta izin Administrator.
5. Selesai! Antivirus Ancaman otomatis:
   * Terpasang di `C:\Program Files\Ancaman`
   * Ikon perisai aktif di **System Tray** (Taskbar dekat jam)
   * Otomatis berjalan saat komputer dihidupkan (*Windows Boot Auto-Start*)
   * Lisensi Community aktif gratis selamanya.
